A tiny deterministic Python program that writes the line to `/output/entry.txt`. Built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Writes one line (83 characters) to `output/entry.txt`. No network, no randomness, no dependencies — the same bytes on every run.
